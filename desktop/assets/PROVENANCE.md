# AGILA brand assets

The user supplied the black-and-white AGILA brand board and authorized adapting its eagle/A identity for the command center and mobile apps.

The vector sources are in public/brand/. The script scripts/generate-brand-assets.mjs creates the desktop PNG and ICO, web icons, Android vector, and iPhone assets from those sources.

Only agila.ico and agila-mark.png are included in the Windows package.
